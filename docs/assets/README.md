# README visual

`workspace.png` is a capture of the interactive workspace demo at https://ponymux.com/, taken on September 12, 2026. It uses the website’s sample tasks and is labeled as a demo in the main README.

Capture settings: dark color scheme, 1440 × 1100 browser viewport, 2× device scale. Wait for fonts and images, isolate the `app-shell-demo` element from the homepage scroll animation, and capture that element at its native 1200 × 700 CSS size with animations disabled.

Update this image when the main workspace layout or the demonstrated behavior changes. Small UI changes do not require a new capture. Keep the image local to this repository so the README does not depend on a changing website asset URL.
